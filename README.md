# claim_doc skills

ชุด skill สำหรับงานเคลมของโรงพยาบาล ใช้ได้กับ Claude Code, Codex และ Antigravity

| Skill                | ทำอะไร                                                                                                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fdh-pre-validate` | สร้างระบบ web app ตรวจสอบข้อมูล 16 แฟ้ม FDH จากฐาน HOSxP ก่อนส่งเคลม ด้วยเงื่อนไขรหัสติด C ของ e-Claim สปสช. |

## สิ่งที่ต้องมีก่อนติดตั้ง

- Node.js 18 ขึ้นไป (เช็กด้วย `node -v`)
- Git (คำสั่ง `npx github:` ใช้ git ดึง repo)
- agent อย่างน้อยหนึ่งตัว: Claude Code, Codex หรือ Antigravity

## ติดตั้ง

เปิด terminal ที่โฟลเดอร์โปรเจกต์ที่จะใช้ skill แล้วรัน:

```
npx github:tehnplk/claim_doc
```

คำสั่งนี้ติดตั้งทุก skill ลงในโปรเจกต์ปัจจุบัน ให้ครบทั้งสาม agent จากนั้นเปิด agent ใหม่อีกครั้งเพื่อให้เห็น skill

### ตัวเลือก

| ต้องการ                                                   | คำสั่ง                                                                                                               |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| ดูว่ามี skill อะไรบ้าง                            | `npx github:tehnplk/claim_doc --list`                                                                                    |
| ติดตั้งเฉพาะบาง skill                             | `npx github:tehnplk/claim_doc fdh-pre-validate`                                                                          |
| ติดตั้งให้ agent เดียว                            | `npx github:tehnplk/claim_doc --agent claude` (หรือ `codex`, `antigravity` คั่นหลายตัวด้วย `,`) |
| ติดตั้งระดับ user ใช้ได้ทุกโปรเจกต์ | `npx github:tehnplk/claim_doc --global`                                                                                  |
| ติดตั้งทับของเดิม                               | `npx github:tehnplk/claim_doc --force`                                                                                   |
| ติดตั้งรุ่นที่ระบุ                             | `npx github:tehnplk/claim_doc#v0.1.0`                                                                                    |

### skill ถูกติดตั้งไว้ที่ไหน

| Agent       | ในโปรเจกต์ (ค่าเริ่มต้น) | ระดับ user (`--global`)           |
| ----------- | --------------------------------------------- | ---------------------------------------- |
| Claude Code | `.claude/skills/<skill>`                    | `~/.claude/skills/<skill>`             |
| Codex       | `.agents/skills/<skill>`                    | `~/.agents/skills/<skill>`             |
| Antigravity | `.agents/skills/<skill>`                    | `~/.gemini/antigravity/skills/<skill>` |

แนะนำให้ติดตั้งในโปรเจกต์ เพราะตำแหน่งระดับ user ของ Codex และ Antigravity อาจต่างกันตามรุ่นของโปรแกรม

## ใช้งาน

เปิด agent ในโปรเจกต์ที่ติดตั้งแล้ว พิมพ์:

```
ทำระบบตรวจสอบ 16 แฟ้ม ด้วย skill fdh-pre-validate
```

agent จะถามว่าจะทำ web app ด้วย Next.js หรือ Python Flask และถามข้อมูลเชื่อมต่อฐาน HOSxP ก่อนเริ่มสร้าง

สิ่งที่ควรรู้ก่อนใช้ `fdh-pre-validate`:

- ระบบสร้างตาราง 1 ตัวและ view 19 ตัวในฐาน HOSxP ชื่อขึ้นต้น `fdh_` ทั้งหมด ไม่แก้ตารางเดิม ควรลองกับฐานทดสอบก่อน
- กฎตรวจมี 22 รหัสจากรหัสติด C ทั้งหมด 680 รหัส ผล "ไม่พบ" จึงไม่ได้แปลว่าจะไม่ติด C
- รหัสที่ สปสช. ต้องเทียบกับฐานของตัวเอง เช่น C305 และ C349 ตรวจจากฝั่งโรงพยาบาลไม่ได้

## อัปเดต

รันคำสั่งติดตั้งอีกครั้งพร้อม `--force`:

```
npx github:tehnplk/claim_doc --force
```

`--force` ลบโฟลเดอร์ skill เดิมแล้วลงใหม่ ถ้าเคยแก้ไฟล์ใน skill ที่ติดตั้งไว้ (เช่น เพิ่มกฎตรวจใน `sql/02_c_check.sql`) ให้สำรองไว้ก่อน

## ถอนการติดตั้ง

ลบโฟลเดอร์ของ skill ออกจากตำแหน่งที่ติดตั้งตามตารางข้างบน เช่น `.claude/skills/fdh-pre-validate` และ `.agents/skills/fdh-pre-validate`
